# Бизнес-требования к скрипту Power Query

## 1. Назначение скрипта
Скрипт предназначен для автоматического сбора, обработки и объединения данных из пяти смарт-таблиц, расположенных на листе `Данные`, с последующим обогащением данными из соответствующих таблиц параметров, выявлением дублей и формированием итоговой сводной таблицы.

## 2. Входные данные

### 2.1. Источник данных
- Файл: Текущая книга Excel 2016.
- Лист: `Данные`.

### 2.2. Смарт-таблицы с данными
| Имя таблицы | Колонки |
|-------------|---------|
| `_data_base1` | ТАБЕЛЬНЫЙ НОМЕР, ПОКАЗАТЕЛЬ |
| `_data_base2` | ТАБЕЛЬНЫЙ НОМЕР, ПОКАЗАТЕЛЬ |
| `_data_base3` | ТАБЕЛЬНЫЙ НОМЕР, ПОКАЗАТЕЛЬ |
| `_data_base4` | ТАБЕЛЬНЫЙ НОМЕР, ПОКАЗАТЕЛЬ |
| `_data_base5` | ТАБЕЛЬНЫЙ НОМЕР, ПОКАЗАТЕЛЬ |

### 2.3. Смарт-таблицы с параметрами
Каждая таблица параметров имеет **две колонки без заголовков**:
- **Колонка 1** — название параметра (ключ)
- **Колонка 2** — значение параметра

| Имя таблицы | Ключи параметров |
|-------------|------------------|
| `_param_base1` | CONTEST_CODE, TOURNAMENT_CODE, PLAN_VALUE, CONTEST_DATE |
| `_param_base2` | CONTEST_CODE, TOURNAMENT_CODE, PLAN_VALUE, CONTEST_DATE |
| `_param_base3` | CONTEST_CODE, TOURNAMENT_CODE, PLAN_VALUE, CONTEST_DATE |
| `_param_base4` | CONTEST_CODE, TOURNAMENT_CODE, PLAN_VALUE, CONTEST_DATE |
| `_param_base5` | CONTEST_CODE, TOURNAMENT_CODE, PLAN_VALUE, CONTEST_DATE |

## 3. Правила обработки данных

### 3.1. Обработка табельного номера
- Значение из колонки `ТАБЕЛЬНЫЙ НОМЕР` преобразуется в текст.
- Дополняется **лидирующими нулями** до **20 символов**.
- Результат помещается в колонку `MANAGER_PERSON_NUMBER`.

### 3.2. Обогащение параметрами
Для каждой строки данных подставляются параметры из соответствующей таблицы `_param_baseX`:
- `CONTEST_CODE` → колонка `CONTEST_CODE`
- `TOURNAMENT_CODE` → колонка `TOURNAMENT_CODE`
- `CONTEST_DATE` → колонка `CONTEST_DATE`
- `PLAN_VALUE` → колонка `PLAN_VALUE` (текст, формат `0.00000`)

### 3.3. Обработка показателя (факта)
- Значение из колонки `ПОКАЗАТЕЛЬ` преобразуется в число.
- **Разделитель дробной части**: запятая `,` заменяется на точку `.`.
- Результат сохраняется в двух форматах:
  - `FACT_VALUE` — текст, формат `0.00000` (точка как разделитель)
  - `FACT_VALUE_число` — число (для суммирования)

### 3.4. Поле приоритета
- Во все строки добавляется колонка `priority_type` со значением `"1"`.

## 4. Объединение данных
- Все строки из пяти таблиц `_data_base1`–`_data_base5` объединяются в одну таблицу.

## 5. Выявление дублей

### 5.1. Ключ дубля
Дубли определяются по составному ключу:
```
CONTEST_CODE + "|" + TOURNAMENT_CODE + "|" + MANAGER_PERSON_NUMBER
```

### 5.2. Логика
- Для каждого уникального ключа подсчитывается количество вхождений.
- Если количество **больше 1** — дубль найден.

### 5.3. Выходные колонки по дублям
| Колонка | Значение |
|---------|----------|
| `ДУБЛЬ` | Количество дублей (если >1), иначе `"-"` |
| `СУММА ПО ТАБЕЛЬНОМУ` | Сумма `FACT_VALUE_число` по ключу (текст, формат `0.00000`), иначе `"-"` |
| `В ФОРМАТЕ` | То же, что и `СУММА ПО ТАБЕЛЬНОМУ` |

## 6. Выходные данные

### 6.1. Состав колонок (порядок следования)

| № | Имя колонки | Тип | Формат / Примечание |
|---|-------------|-----|---------------------|
| 1 | MANAGER_PERSON_NUMBER | Текст | 20 символов, лидирующие нули |
| 2 | CONTEST_CODE | Текст | из параметров |
| 3 | TOURNAMENT_CODE | Текст | из параметров |
| 4 | CONTEST_DATE | Текст | из параметров |
| 5 | PLAN_VALUE | Текст | `0.00000` (точка) |
| 6 | FACT_VALUE | Текст | `0.00000` (точка) |
| 7 | priority_type | Текст | всегда `"1"` |
| 8 | ДУБЛЬ | Текст | число или `"-"` |
| 9 | СУММА ПО ТАБЕЛЬНОМУ | Текст | `0.00000` или `"-"` |
| 10 | В ФОРМАТЕ | Текст | `0.00000` или `"-"` |
| 11 | PLAN_VALUE_число | Число | оригинальное число (с запятой в Excel) |
| 12 | FACT_VALUE_число | Число | оригинальное число (с запятой в Excel) |

## 7. Особые требования к реализации
- Все этапы обработки должны быть **названы на русском языке** без пробелов (допустим символ `_`).
- Переменные, пути и настройки выносятся в **начало скрипта**.
- Исходные данные не изменяются.
- Скрипт должен работать в **Excel 2016** (Power Query).
- Ошибки при преобразовании чисел обрабатываются: некорректное значение заменяется на `0`.
- Разделитель дробной части во входных данных — **запятая**.
- Разделитель дробной части в текстовых выходных колонках — **точка**.

# Финальная версия скрипта

```pq
let
    // ==================== НАСТРОЙКИ ====================
    ФорматЧисла = "0.00000",
    ДлинаТабельногоНомера = 20,
    // ===================================================

    // Шаг_01_Получаем_все_смарт_таблицы_книги
    Источник = Excel.CurrentWorkbook(),

    // Шаг_02_Загружаем_таблицы_данных
    ТаблицаДанных_1 = Источник{[Name="_data_base1"]}[Content],
    ТаблицаДанных_2 = Источник{[Name="_data_base2"]}[Content],
    ТаблицаДанных_3 = Источник{[Name="_data_base3"]}[Content],
    ТаблицаДанных_4 = Источник{[Name="_data_base4"]}[Content],
    ТаблицаДанных_5 = Источник{[Name="_data_base5"]}[Content],

    // Шаг_03_Загружаем_таблицы_параметров
    ТаблицаПараметров_1 = Источник{[Name="_param_base1"]}[Content],
    ТаблицаПараметров_2 = Источник{[Name="_param_base2"]}[Content],
    ТаблицаПараметров_3 = Источник{[Name="_param_base3"]}[Content],
    ТаблицаПараметров_4 = Источник{[Name="_param_base4"]}[Content],
    ТаблицаПараметров_5 = Источник{[Name="_param_base5"]}[Content],

    // Шаг_04_Функция_преобразования_строки_с_запятой_в_число
    ИзЗапятойВЧисло = (Значение as any) as number =>
        let
            Текст = Text.From(Значение),
            СТочкой = Text.Replace(Текст, ",", "."),
            Очищено = Text.Trim(СТочкой),
            Результат = try Number.From(Очищено) otherwise 0
        in
            Результат,

    // Шаг_05_Функция_извлечения_значения_параметра_как_текст
    ПолучитьПараметрТекст = (Таблица as table, Ключ as text) as text =>
        let
            Строки = Table.ToRows(Таблица),
            Найдено = List.Select(Строки, each List.Count(_) >= 2 and Text.Trim(Text.From(_{0})) = Ключ),
            Результат = if List.Count(Найдено) > 0 then Text.From(Найдено{0}{1}) else ""
        in
            Результат,

    // Шаг_06_Собираем_параметры_для_каждой_таблицы
    Параметры_1 = [
        CONTEST_CODE = ПолучитьПараметрТекст(ТаблицаПараметров_1, "CONTEST_CODE"),
        TOURNAMENT_CODE = ПолучитьПараметрТекст(ТаблицаПараметров_1, "TOURNAMENT_CODE"),
        PLAN_VALUE_число = ИзЗапятойВЧисло(ПолучитьПараметрТекст(ТаблицаПараметров_1, "PLAN_VALUE")),
        CONTEST_DATE = ПолучитьПараметрТекст(ТаблицаПараметров_1, "CONTEST_DATE")
    ],
    Параметры_2 = [
        CONTEST_CODE = ПолучитьПараметрТекст(ТаблицаПараметров_2, "CONTEST_CODE"),
        TOURNAMENT_CODE = ПолучитьПараметрТекст(ТаблицаПараметров_2, "TOURNAMENT_CODE"),
        PLAN_VALUE_число = ИзЗапятойВЧисло(ПолучитьПараметрТекст(ТаблицаПараметров_2, "PLAN_VALUE")),
        CONTEST_DATE = ПолучитьПараметрТекст(ТаблицаПараметров_2, "CONTEST_DATE")
    ],
    Параметры_3 = [
        CONTEST_CODE = ПолучитьПараметрТекст(ТаблицаПараметров_3, "CONTEST_CODE"),
        TOURNAMENT_CODE = ПолучитьПараметрТекст(ТаблицаПараметров_3, "TOURNAMENT_CODE"),
        PLAN_VALUE_число = ИзЗапятойВЧисло(ПолучитьПараметрТекст(ТаблицаПараметров_3, "PLAN_VALUE")),
        CONTEST_DATE = ПолучитьПараметрТекст(ТаблицаПараметров_3, "CONTEST_DATE")
    ],
    Параметры_4 = [
        CONTEST_CODE = ПолучитьПараметрТекст(ТаблицаПараметров_4, "CONTEST_CODE"),
        TOURNAMENT_CODE = ПолучитьПараметрТекст(ТаблицаПараметров_4, "TOURNAMENT_CODE"),
        PLAN_VALUE_число = ИзЗапятойВЧисло(ПолучитьПараметрТекст(ТаблицаПараметров_4, "PLAN_VALUE")),
        CONTEST_DATE = ПолучитьПараметрТекст(ТаблицаПараметров_4, "CONTEST_DATE")
    ],
    Параметры_5 = [
        CONTEST_CODE = ПолучитьПараметрТекст(ТаблицаПараметров_5, "CONTEST_CODE"),
        TOURNAMENT_CODE = ПолучитьПараметрТекст(ТаблицаПараметров_5, "TOURNAMENT_CODE"),
        PLAN_VALUE_число = ИзЗапятойВЧисло(ПолучитьПараметрТекст(ТаблицаПараметров_5, "PLAN_VALUE")),
        CONTEST_DATE = ПолучитьПараметрТекст(ТаблицаПараметров_5, "CONTEST_DATE")
    ],

    // Шаг_07_Функция_обработки_одной_таблицы_данных
    ОбработатьТаблицу = (Таблица as table, Параметры as record) as table =>
        let
            СТабельным = Table.AddColumn(Таблица, "MANAGER_PERSON_NUMBER", each 
                Text.PadStart(Text.From([ТАБЕЛЬНЫЙ НОМЕР]), ДлинаТабельногоНомера, "0")),
            
            СКодомКонтеста = Table.AddColumn(СТабельным, "CONTEST_CODE", each Параметры[CONTEST_CODE]),
            
            СКодомТурнира = Table.AddColumn(СКодомКонтеста, "TOURNAMENT_CODE", each Параметры[TOURNAMENT_CODE]),
            
            СДатойКонтеста = Table.AddColumn(СКодомТурнира, "CONTEST_DATE", each Параметры[CONTEST_DATE]),
            
            СПлановымЧисло = Table.AddColumn(СДатойКонтеста, "PLAN_VALUE_число", each Параметры[PLAN_VALUE_число]),
            
            СФактическимЧислом = Table.AddColumn(СПлановымЧисло, "FACT_VALUE_число", each 
                ИзЗапятойВЧисло([ПОКАЗАТЕЛЬ])),
            
            СПлановымТекст = Table.AddColumn(СФактическимЧислом, "PLAN_VALUE", each 
                Number.ToText([PLAN_VALUE_число], ФорматЧисла)),
            
            СФактическимТекст = Table.AddColumn(СПлановымТекст, "FACT_VALUE", each 
                Number.ToText([FACT_VALUE_число], ФорматЧисла)),
            
            СПриоритетом = Table.AddColumn(СФактическимТекст, "priority_type", each "1"),
            
            Результат = Table.SelectColumns(СПриоритетом, {
                "MANAGER_PERSON_NUMBER", "CONTEST_CODE", "TOURNAMENT_CODE",
                "CONTEST_DATE", "PLAN_VALUE", "FACT_VALUE", 
                "PLAN_VALUE_число", "FACT_VALUE_число", "priority_type"
            })
        in
            Результат,

    // Шаг_08_Обрабатываем_каждую_таблицу
    ОбработанныеДанные_1 = ОбработатьТаблицу(ТаблицаДанных_1, Параметры_1),
    ОбработанныеДанные_2 = ОбработатьТаблицу(ТаблицаДанных_2, Параметры_2),
    ОбработанныеДанные_3 = ОбработатьТаблицу(ТаблицаДанных_3, Параметры_3),
    ОбработанныеДанные_4 = ОбработатьТаблицу(ТаблицаДанных_4, Параметры_4),
    ОбработанныеДанные_5 = ОбработатьТаблицу(ТаблицаДанных_5, Параметры_5),

    // Шаг_09_Объединяем_все_таблицы
    ВсеДанные = Table.Combine({
        ОбработанныеДанные_1, ОбработанныеДанные_2,
        ОбработанныеДанные_3, ОбработанныеДанные_4, ОбработанныеДанные_5
    }),

    // Шаг_10_Создаём_ключ_для_поиска_дублей
    СКлючом = Table.AddColumn(ВсеДанные, "ВнутреннийКлюч", each 
        [CONTEST_CODE] & "|" & [TOURNAMENT_CODE] & "|" & [MANAGER_PERSON_NUMBER]),

    // Шаг_11_Группируем_по_ключу
    Группировка = Table.Group(СКлючом, {"ВнутреннийКлюч"}, {
        {"Количество", each Table.RowCount(_), Int64.Type},
        {"СуммаЗначений", each List.Sum([FACT_VALUE_число]), type number}
    }),

    // Шаг_12_Добавляем_информацию_о_дублях
    СДублями = Table.NestedJoin(СКлючом, {"ВнутреннийКлюч"}, Группировка, {"ВнутреннийКлюч"}, "ДанныеГруппировки", JoinKind.LeftOuter),

    // Шаг_13_Разворачиваем_вложенную_таблицу
    СРазвернутымиДанными = Table.ExpandTableColumn(СДублями, "ДанныеГруппировки", {"Количество", "СуммаЗначений"}, {"Количество", "СуммаЗначений"}),

    // Шаг_14_Заменяем_null_на_0_или_1
    СЗаменойNull = Table.ReplaceValue(СРазвернутымиДанными, null, 1, Replacer.ReplaceValue, {"Количество"}),
    СЗаменойNull2 = Table.ReplaceValue(СЗаменойNull, null, 0, Replacer.ReplaceValue, {"СуммаЗначений"}),

    // Шаг_15_Колонка_ДУБЛЬ
    СКолонкойДубль = Table.AddColumn(СЗаменойNull2, "ДУБЛЬ", each 
        if [Количество] > 1 then [Количество] else "-"),

    // Шаг_16_Колонка_СУММА_ПО_ТАБЕЛЬНОМУ
    СКолонкойСумма = Table.AddColumn(СКолонкойДубль, "СУММА ПО ТАБЕЛЬНОМУ", each 
        if [Количество] > 1 then Number.ToText([СуммаЗначений], ФорматЧисла) else "-"),

    // Шаг_17_Колонка_В_ФОРМАТЕ
    СКолонкойФормат = Table.AddColumn(СКолонкойСумма, "В ФОРМАТЕ", each 
        if [Количество] > 1 then Number.ToText([СуммаЗначений], ФорматЧисла) else "-"),

    // Шаг_18_Удаляем_служебные_колонки
    УдаленыСлужебные = Table.RemoveColumns(СКолонкойФормат, {
        "ВнутреннийКлюч", "Количество", "СуммаЗначений"
    }),

    // Шаг_19_Переставляем_колонки
    ИтоговаяТаблица = Table.ReorderColumns(УдаленыСлужебные, {
        "MANAGER_PERSON_NUMBER", "CONTEST_CODE", "TOURNAMENT_CODE",
        "CONTEST_DATE", "PLAN_VALUE", "FACT_VALUE", "priority_type",
        "ДУБЛЬ", "СУММА ПО ТАБЕЛЬНОМУ", "В ФОРМАТЕ",
        "PLAN_VALUE_число", "FACT_VALUE_число"
    })
in
    ИтоговаяТаблица
```
