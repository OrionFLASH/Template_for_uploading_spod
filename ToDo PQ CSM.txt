Для Excel 2016 русский надо написать скрипо на PowreQ
Скрипт делаем единый (те один)
в скрипте делаем так чтобы в интерфейсе PQ видеть все этапы отдельно
Если в скрипте используются имена пути значнеия названия пременных указываем их все в начале скрипта
Этапы скрипта именуем русскими названиями без пробелов используем _ вместо пробела если нужно или не используем пробелы вовсе

в текущем файле эксель есть 5 Смарт таблиц на листе "Данные"
с именами
_data_base1
_data_base2
_data_base3
_data_base4
_data_base5

в каждой из них по две колонки
ТАБЕЛЬНЫЙ НОМЕР
ПОКАЗАТЕЛЬ

также на этом листе пристутсвует для каждой таблице соответвтующий ей блок с параметрами который задан именем
_param_base1
_param_base2
_param_base3
_param_base4
_param_base5

соотвествие
_data_base1 : _param_base1
_data_base2 : _param_base2
_data_base3 : _param_base3
_data_base4 : _param_base4
_data_base5 : _param_base5

в этом поименованном блоке в каждом 
CONTEST_CODE	01_2026-1_07-5_1
TOURNAMENT_CODE	t_01_2026-1_07-5_1_4001
PLAN_VALUE	1000000.00000
CONTEST_DATE	2026-05-25
Бизнес-блок	KMKKSB

в первой колонке (без заголовков) название параметра
CONTEST_CODE
TOURNAMENT_CODE
PLAN_VALUE
CONTEST_DATE
Бизнес-блок

а во второй колонке значение
01_2026-1_07-5_1
t_01_2026-1_07-5_1_4001
1000000.00000
2026-05-25
KMKKSB


Задача:
надо собрать из всех таблиц сводную таблицу
в таблицу надо собрать из каждой _data_base все даныне
и разместить по колонкам
первые две это дубль значений из текущей таблицы
а далее колонки (все в текстовом формате)
- MANAGER_PERSON_NUMBER = значению из "ТАБЕЛЬНЫЙ НОМЕР" в текстовом виде приведенное к 20 знакам с лидирующими нулями
00673892 => 00000000000000673892
- CONTEST_CODE = значению строки CONTEST_CODE из соответстующей _param_base
- TOURNAMENT_CODE = значению строки TOURNAMENT_CODE из соответстующей _param_base
- CONTEST_DATE = значению строки CONTEST_DATE из соответстующей _param_base
- PLAN_VALUE = значению строки PLAN_VALUE из соответстующей _param_base
- FACT_VALUE = значению "ПОКАЗАТЕЛЬ" из _data_base или из текущей строки в начале приведя его в формат: 0.00000 те разделитель разряда "." и 5 знаков после точки
4,7 = 4.70000; 0,8 = 0.80000, 9 = 9.00000 
- priority_type = всегда = 1

добавляем еще 2 колонки: "ДУБЛЬ" и "СУММА ПО ТАБЕЛЬНОМУ"
далее надо в итоговом списке найти (проверить) наличие дублей по ключу: CONTEST_CODE + TOURNAMENT_CODE + MANAGER_PERSON_NUMBER
если дубль найден то добавляем в колонку ДУБЛЬ число найденных дублей, если дублей нет, то в этом поле ставим "-"
также для найденных дублей в колонку СУММА ПО ТАБЕЛЬНОМУ записываем сумму значнений из ПОКАЗАТЕЛЬ по данному ключу. Если дубей нет то ставим "-"
рядом еще одна колонка "В ФОРМАТЕ" в которую надо поместить преобразованное значение суммы из колонки "СУММА ПО ТАБЕЛЬНОМУ" приведенная к формату как и FACT_VALUE 0.00000
